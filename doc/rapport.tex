\section{Introduction}
Ce document présente la mise en œuvre de la persistance des données pour le projet SEPA26. L'architecture repose sur MariaDB pour le stockage.

\section{Gestion de la Base de Données}
Le choix s'est porté sur \textbf{MariaDB}, une base de données relationnelle performante et open-source.

\subsection{Conteneurisation avec Docker}
L'instance MariaDB est déployée via \texttt{docker-compose.yml}. Cette approche garantit la portabilité de l'environnement de développement et de production. Par mesure de sécurité, les identifiants sont externalisés dans un fichier \texttt{.env}.

\begin{lstlisting}[language=yaml, caption=Configuration Docker Compose]
services:
  mariadb:
    image: mariadb:latest
    container_name: sepa26-db
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: ${MYSQL_DATABASE}
      MYSQL_USER: ${MYSQL_USER}
      MYSQL_PASSWORD: ${MYSQL_PASSWORD}
    volumes:
      - mariadb_data:/var/lib/mysql
\end{lstlisting}

\subsection{Persistance des Données}
Conformément aux exigences de pérennité, un \textbf{volume Docker} nommé \texttt{mariadb\_data} est utilisé. Les données sont stockées sur l'hôte physique, ce qui permet de conserver les informations même si le conteneur est supprimé ou mis à jour.

\section{Conclusion}
L'utilisation de Docker pour la base de données assure une infrastructure robuste et sécurisée contre la perte de données.
