\section{Introduction}

Ce projet porte sur la réalisation du service REST SEPA26. L'objectif est de construire une architecture basé sur la norme ISO 20022 fourni en cours pour gérer des transactions. Le déploiement est automatisé sur une VM via Jenkins. \\
Il est réalisé par Umm-Habibah Ouattara et Florian Pépin.

\section{Architecture du Projet}

\subsection{Stack Technique}
Le service SEPA26 repose sur une architecture Java 21. La stack technique mis en place est le suivant :
\begin{itemize}
    \item \textbf{Framework :} Spring Boot. Spring Web est utilisé pour l'exposition des API REST et Spring Data JPA pour la persistance des données.
    \item \textbf{Gestion des dépendances et Build :} Maven.
    \item \textbf{Stockage des données :} MariaDB et H2 (base de données embarquée pour les tests).
    \item \textbf{Traitement XML :} Les échanges se font au format XML en respectant la norme ISO 20022. Le projet intègre JAXB et Jackson-XML pour la sérialisation/désérialisation, ainsi que Saxon-HE pour des manipulations avancées (XSLT/XPath).
	\item \textbf{Interface (Front-end) :} Le projet utilise Thymeleaf pour
  générer les pages web. Cela permet de transformer et d'afficher les données Java/XML en pages HTML.
\end{itemize}

\subsection{Points d'accès (Endpoints)}
L'API est organisée autour de la ressource "Transaction". Le tableau suivant récapitule les principaux points d'entrée du service sous le préfixe \texttt{/sepa26} :

    \small
    \begin{tabularx}{\textwidth}{|l|l|X|}
        \hline
        \textbf{Méthode} & \textbf{Endpoint} & \textbf{Description / Format de sortie} \\
        \hline
        \texttt{POST} & \texttt{/insert} & Création d'un virement (Flux XML ISO 20022) \\

        \hline
        \texttt{GET} & \texttt{/search} & Recherche avancée de transactions (XML) \\
        \hline
    \end{tabularx}
    \caption{Récapitulatif des services REST}
\end{table}

En complément, l'application propose des pages web classiques (\texttt{/}, \texttt{/help}, \texttt{/transfert}) pour la navigation utilisateur.

\section{Éléments Optionnels}
Nous avons ajouté quelques fonctionnalités pour rendre le service plus simple à utiliser depuis un navigateur :

\begin{itemize}
    \item \textbf{Formulaire d'insertion :} Il est possible d'envoyer un fichier XML directement depuis la page \url{/transfert} sans avoir à passer par une commande \texttt{curl}.
    \item \textbf{Bouton supprimer :} Sur la page des résumés (\url{/resume/html}), nous avons ajouté un bouton pour supprimer une transaction en un clic. C'est plus pratique que de forger une requête \texttt{DELETE} à la main.
    \item \textbf{Collection Postman :} Nous avons fournit le fichier \texttt{sepa26\_pepin\_ouattara.json} qui contient déjà toutes les requêtes prêtes à l'emploi pour tester le serveur (VM).
\end{itemize}
